# 🚀 LangSmith AI Evaluation & Monitoring

## 📌 Overview

This project showcases how to use **LangSmith** to trace, monitor, debug, and evaluate AI applications powered by Large Language Models (LLMs). It provides insights into model behavior, execution flows, and performance, making AI development more reliable and efficient.

---

## ✨ Features

* 🤖 LLM application tracing
* 📊 AI workflow monitoring
* 🔍 Debugging and performance analysis
* 📈 Evaluation of model outputs
* ⚡ Easy integration with AI projects
* 🛠️ Developer-friendly implementation

---

## 🛠️ Technologies Used

* Python
* LangChain
* LangSmith
* OpenAI API
* Environment Variables (`.env`)
* Git & GitHub

## 🚀 Installation

```bash
git clone <repository-url>

cd langsmith_project

pip install -r requirements.txt
```

Create a `.env` file and add your required API keys, then run:

```bash
python app.py
```
